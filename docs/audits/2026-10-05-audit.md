### 3.1 MEDIUM (carried) · C1+C3 — `gpu_worker.py` increments `n_done` on failure, always returns 0

**File:** `analysis/gpu_worker.py` · Lines 359–372

**Class:** C (silent-failure loop) — C3 honest-counting + C1 honest exit code.

`n_done` is incremented on both success and failure paths:

```python
r = _process_one(a, args.db, ar2.value, resolved, args.stems_dir)
if not r.is_ok():
    _log.warning("FAIL track_audio_id=%s: %s", track_audio_id, r.error)
    failed_tids.add(track_audio_id)
    n_done += 1          # ← C3: done counter advanced on failure
    continue
n_done += 1
```

The loop exits via `return 0` at both terminal conditions (queue drained and
`--max-tracks` hit) without calling `exit_status()`. Consequences:

1. A session where every track fails logs "done" and returns 0 — a CI/cron caller
   treats it as success. Compare: `mac_analyze_loop.py` calls
   `exit_status(n_done, n_failed)` which escalates to nonzero+ERROR when
   `n_done == 0` or failure ratio exceeds 50%.
2. `--max-tracks N` is driven by `n_done`. Ten consecutive failures with
   `--max-tracks=10` exhaust the limit without ever successfully analyzing a
   track; the caller receives exit 0.

**Fix:** introduce `n_failed`; increment it (not `n_done`) on the failure path;
call `exit_status(n_done, n_failed)` at both return sites. Mirrors the contract
already in `mac_analyze_loop.py`.

### 3.2 LOW (carried) · B — `mac_analyze_loop.py` sha256 check missing `OSError` guard

**File:** `scripts/mac_analyze_loop.py` · Line 455

```python
if asset.sha256:
    local_sha = sha256_file(local_audio)   # no try/except OSError
    if local_sha != asset.sha256:
```

An `OSError` (rsync exits 0 but the file is unreadable / truncated to 0 bytes)
would propagate uncaught past the outer `except subprocess.CalledProcessError`
handler and terminate the track's processing without calling
`persist_failed_inc()`, under-counting failures.

The equivalent in `set_mert_backfill_loop.py` (now removed) had the guard:
```python
try:
    local_sha = sha256_file(local_audio)
except OSError as exc:
    local_sha = f"<unreadable: {exc}>"
```

**Fix:** wrap `sha256_file(local_audio)` in a `try/except OSError` that either
treats the read failure as a sha mismatch (trigger transient retry) or calls
`register_transient` directly.

### 3.3 LOW (carried) · C3 — `mac_analyze_loop._persist_in_bg` exception scope too narrow

**File:** `scripts/mac_analyze_loop.py` · Lines 419–424

```python
except subprocess.CalledProcessError as e:
    counts.persist_failed_inc()
    log.error("[%d] (bg) push failed: %s", tid, e)
```

An `OSError` (scratch DB path missing after an interrupted run) or
`sqlite3.OperationalError` (lock timeout on the scratch DB write in
`push_track_rows`) would terminate the background thread silently without calling
`persist_failed_inc()`, under-counting persist failures in the Counts tally.

**Fix:** widen the except to `except (subprocess.CalledProcessError, OSError,
sqlite3.OperationalError)`, or catch `Exception` and re-log with type info.
