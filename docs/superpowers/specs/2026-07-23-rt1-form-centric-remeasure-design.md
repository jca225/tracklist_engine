# RT1 form-centric re-measure — design

**Date:** 2026-07-23
**Status:** approved (definition signed off), pre-implementation
**Branch:** `fix/rt1-form-centric-remeasure` (stacked on `fix/gt-scorer-form-coverage` / PR #86)

## Problem

The alignment SSOT numbers (`docs/alignment_status.md`) are generated by
`make scorecard` → `eda/alignment/failure_analysis/build_span_table.py` →
`analyze.py`. `build_span_table` emits **one row per predicted span** and matches
each span to its temporally-nearest GT row (`g = min(rows, key=|Δset_start|)`,
line 188); its coverage check (line 256) is **recording-level** (`matched =
{recording_id}`). `analyze.py` then weights loss by GT-seconds **over the emitted
rows only**.

Consequence: when a recording has more than one GT form — a slot played across a
stem transition (instrumental→full, acappella over instrumental) or a
reprise/loop replayed — the forms no span selects produce **no row**, so their
audible seconds are absent from both the loss numerator and the denominator. The
headline traj/placement/loss numbers are computed over an incomplete GT and are
optimistic. (Router side fixed in PR #85; scorer *visibility* in PR #86; this is
the SSOT *denominator* fix — the RT1 honest re-measure sketched in
`docs/alignment_state_of_record.md` §3.)

## Signed-off definition

- **Denominator:** full-loss form-centric. Every GT form's audible-seconds enter
  the denominator once; a form no span is assigned to counts as 100% lost
  (traj-acc 0, placement miss).
- **Assignment:** injective per recording — each span assigned to at most one GT
  form and vice versa (greedy nearest, no reuse). Fixes double-counting a form's
  seconds across two reprise spans and gives a reprise span credit for its *own*
  form.
- **Placement median:** over rows-with-a-prediction only (n labeled). Placement
  `<5s`/`<15s` **rates** and **traj-acc** count unmatched forms as failures in
  the denominator.
- **Identity:** unchanged (already overlap-based, not nearest).

## Design

### 1. Injective assignment (`build_span_table.py`)

Group predicted spans by `recording_id` and GT forms by `track_id`. Per
recording, build all (span, form) pairs, sort by ascending `|Δset_start|`, and
assign greedily skipping any span or form already used. (Greedy is optimal for
the ≤-handful sets here; no Hungarian needed.) Result:

- **Assigned (span, form):** per-span row as today, but scored against the
  *assigned* form (not the global-nearest). For the 1-span/1-form case this is
  identical to current behavior.
- **Unassigned form** (more forms than spans): synthetic row —
  `gt_audible_s` = form audible seconds (same `_audible_intervals` path the
  normal rows use), `traj_strict = 0`, `set_start_err_s = None`,
  `pred_* = None`, `gt_stem = form.claimed_stem`, `span_class` = the form's
  class, `binding_cause = "unrecovered_form"`.
- **Unassigned span** (more spans than forms): identity-only row, `seconds = 0`
  (as today's no-GT span).

### 2. `analyze.py`

Register `unrecovered_form` as a dependency-ordered binding cause, placed
**upstream of placement** (the aligner never represented the appearance at all).
Seconds-weighted loss (`sec_lost = seconds * (1 - traj_strict)`) now sums over
all forms once; `tot_sec` grows by the unmatched forms' seconds and `tot_lost`
grows by the same (traj=0 → full loss).

### 3. Metric rules

- Placement **median**: rows with a non-null `set_start_err_s` (= matched spans),
  n labeled `(n matched)`.
- Placement **`<5s`/`<15s` rates** and **traj-acc**: denominator = matched rows
  ∪ unmatched-form rows (the latter always fail / traj=0).
- Identity aggregates: unchanged.

## Components / boundaries

- `never_matched.unmatched_gt_forms` (from PR #86) is the single source for
  "which forms were selected"; `build_span_table` reuses it (hence the stack on
  #86). If #86 is reworked, this rebases.
- `build_span_table.py` owns row emission (assignment + synthetic rows).
- `analyze.py` owns aggregation + the new binding cause.
- No canonical/pi writes; Mac-local run over the committed `_lt` timelines.

## Testing (TDD)

Unit tests on `build_span_table` row emission:

1. **Reprise** (1 recording, 2 forms, 2 spans near each) → two rows, each scored
   against its own form; each form's seconds counted once (no double-count).
2. **Unmatched form** (2 forms, 1 span) → one normal row + one
   `unrecovered_form` row carrying the second form's full audible seconds,
   `traj_strict = 0`.
3. **Regression pin** (1 form, 1 span) → row identical to current output
   (asserts single-form sets are numerically unchanged).
4. **More spans than forms** → extra span is identity-only, `seconds = 0`.

Then: run the scorer on `2nvzlh2k` + `1fsnxchk` `_lt` timelines Mac-local,
regenerate `docs/alignment_status.md` (dated + SHA) with a **methodology-change
note** ("RT1 form-centric denominator — not comparable to pre-`<SHA>` figures").

  (Crush-abstained) — those never bridge to a span; that is Crush Phase-B
  completeness, blocked on the pi deploy (issue #73).
- Any change to per-span *identity* scoring.
- Changing the router (PR #85) or the score_timeline_vs_gt print line (PR #86).
